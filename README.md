# Frisian-ASR
Fine-tuning XLS-R on multilingual data. The model can be configured to finetune the pretrained model on 4 West Germanic languages, namely Dutch, German and English. This repo implement the paper: "Amooie, R., De Vries, W., Hao, Y., Dijkstra, J., Coler, M., & Wieling, M. (2025, April). Enhancing Standard and Dialectal Frisian ASR: Multilingual Fine-tuning and Language Identification for Improved Low-resource Performance. In ICASSP 2025-2025 IEEE International Conference on Acoustics, Speech and Signal Processing (ICASSP) (pp. 1-5). IEEE."
